# Shopify App Store Feature Image 2026 Reference

Snapshot verified: 2026-05-03.

Primary official sources:

- Shopify App Store best practices: https://shopify.dev/docs/apps/launch/shopify-app-store/best-practices
- Shopify App Store requirements: https://shopify.dev/docs/apps/launch/shopify-app-store/app-store-requirements

## Required/Expected Media Standard

Feature images are used as feature media in an app listing. Shopify recommends a short promotional video first; if no video is available, use a static feature image that conveys the app's benefit or unique value.

Feature image specification:

- `1600px by 900px`
- `16:9`
- Static image should communicate benefit or unique value
- Keep the image simple
- Use one focal point
- Use solid backgrounds with good contrast
- Include alt text
- Do not use Shopify logos
- Do not repeat the app card subtitle in the image

## Related App Icon Standard

Do not confuse feature images with app icons. App icons use:

- `1200px by 1200px`
- JPEG or PNG
- Square corners because Shopify rounds them automatically
- Padding so the logo does not touch edges
- No text, screenshots, or Shopify trademarks

## Listing Image Rejection Checklist

Reject or revise images that include:

- Pricing information in listing images or icon
- Statistics, rankings, data points, or guarantees
- Phrases like "the first", "the best", "the only", "#1", "most powerful"
- Reviews, testimonials, ratings, merchant quotes, or star ratings
- Shopify trademarks in app icon, banner, or screenshots
- Feature image or screenshot made only of the app logo
- Duplicate or near-identical images across the listing
- Browser windows, desktop backgrounds, or irrelevant surrounding UI in screenshots

## Practical Quality Checklist

Before finalizing:

- One message is understandable in under 3 seconds.
- The focal point is clear at thumbnail size.
- Any text remains readable at reduced display size.
- The image does not promise a result the app cannot actually deliver.
- The visual matches the app's real product category and brand.
- Alt text states the visible benefit without marketing exaggeration.
